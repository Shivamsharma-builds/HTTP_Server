ABOUT

How it works

This project implements a basic HTTP server without using frameworks such as Express, Apache or Nginx.

🌐 Raw TCP Sockets

The server communicates directly with clients using Linux TCP sockets.

⚡ Non-blocking I/O

Connections use non-blocking sockets so the server can handle multiple clients efficiently.

🔄 epoll

Linux epoll is used to monitor multiple connections without creating a thread for every client.

FEATURES

What the server supports

GET

GET Requests

Serve HTML, CSS, JavaScript and other static files.

POST

File Upload

Upload files to the server using HTTP POST requests.

GET

File Download

Download previously uploaded files through HTTP.

DEL

File Deletion

Delete files using HTTP DELETE requests.

API

Available endpoints

GET /

Serve the home page.

GET /about

Display information about the server.

GET /contact

Display contact information.

POST /upload

Upload a file to the server.

GET /files/:filename

Download an uploaded file.

DELETE /files/:filename

Delete an uploaded file.

EXAMPLES

Try the server

# Test the home page
curl -i http://127.0.0.1:8080/

# Upload a file
curl -X POST \
  --data-binary @somefile.txt \
  -H "X-Filename: somefile.txt" \
  http://127.0.0.1:8080/upload

# Download a file
curl http://127.0.0.1:8080/files/somefile.txt

# Delete a file
curl -X DELETE \
  http://127.0.0.1:8080/files/somefile.txt
