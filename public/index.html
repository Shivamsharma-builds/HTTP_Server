It works! 🎉

This page is being served by a hand-written C++ HTTP server using raw TCP sockets and non-blocking I/O (epoll).

Try it out:

  • curl -i http://127.0.0.1:8080/
  • curl -X POST --data-binary @somefile.txt -H "X-Filename: somefile.txt" http://127.0.0.1:8080/upload
  • curl http://127.0.0.1:8080/files/somefile.txt
  • curl -X DELETE http://127.0.0.1:8080/files/somefile.txt
